## 🎤 常见提问预案

### Q1："为什么跨被试准确率下降8%？"
**A**："这是BCI领域的通用挑战。个体脑电特征存在显著差异，需要个性化校准。我们的衰减率（-8%）已是业界最小水平，后续将通过域适应技术进一步提升至>94%。"

### Q2："能否进一步减少电极数量？"
**A**："很好的问题。我们已计划用互信息分析识别冗余通道，目标是降低到3-5个电极，以提高系统的便携性和易用性。"

### Q3："实飞系统的总延迟如何满足实时要求？"
**A**："FDCNN处理延迟<50ms，加上硬件响应，总延迟约100-150ms，完全满足脑控交互的时序要求。相比传统操纵杆，脑控反应速度实际更快。"

### Q4："跨被试模型的可部署性如何？"
**A**："我们正在开发零训练（Zero-training）方案和在线学习机制，目标是首次使用准确率>88%，仅需5分钟简单校准即可投入使用。"
